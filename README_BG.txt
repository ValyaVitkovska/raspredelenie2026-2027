УЧЕБЕН ПЛАН – МАТЕМАТИКА (PWA)
================================

Какво прави:
- Инсталира се като приложение на Windows лаптоп и Android телефон.
- Работи офлайн и пази отметките локално.
- Позволява дата и бележка към всеки час.
- Бутон „Редактирай“ позволява да променяте темата и вида на урока; редакцията се синхронизира между устройствата.
- Има търсене, филтър, прогрес, архив/възстановяване.
- Може да се синхронизира между устройствата чрез Firebase.

1) КАЧВАНЕ В GITHUB PAGES
- Създайте ново хранилище, напр. ucheben-plan-matematika.
- Качете ВСИЧКИ файлове и папката icons от този архив.
- Settings -> Pages -> Deploy from a branch -> main / root.
- След публикуване отворете адреса в Chrome/Edge.

2) ИНСТАЛИРАНЕ
Windows (Edge/Chrome): отворете сайта -> бутон „Инсталирай“ или иконата за инсталиране в адресната лента.
Android (Chrome): отворете сайта -> меню -> „Инсталиране на приложение“ / „Добавяне към началния екран“.

3) СИНХРОНИЗАЦИЯ (по желание)
За да са еднакви отметките на телефона и лаптопа:
A. Създайте безплатен Firebase проект: https://console.firebase.google.com/
B. Authentication -> Sign-in method -> включете Email/Password.
C. Firestore Database -> Create database.
D. В Firestore -> Rules поставете съдържанието на файла firebase.rules и публикувайте правилата.
E. Project settings -> Your apps -> Web app -> SDK setup and configuration -> копирайте firebaseConfig.
F. В приложението натиснете „Синхронизация“, поставете config, въведете имейл и парола и натиснете „Създай профил“.
G. На второто устройство използвайте СЪЩИЯ Firebase config и СЪЩИЯ имейл/парола, после „Вход“.

ВАЖНО:
- Firebase config не е парола; сигурността се осигурява от Authentication + Firestore Rules.
- Данните се пазят локално дори без Firebase.
- При първо свързване към облака приложението качва текущото локално състояние, ако в облака няма данни.
